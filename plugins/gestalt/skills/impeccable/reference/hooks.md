# Project hooks

The managed Gestalt adaptation does not install Impeccable project hooks or
standalone command shortcuts. Do not run `hooks`, `hook-admin`, `pin`, or
`skills install` to enable Live. Native admission verifies trusted configuration;
project-installed executable hooks are not a substitute. For ordinary design
review use [audit.md](audit.md) and [craft-floor.md](craft-floor.md). Existing
operator configuration is preserved; report a conflict instead of changing it
as a side effect.
