## Downstream changes

- Aligns query field descriptions with the smallest sufficient related set and
  focused followups rather than fixed broad-query counts or one-shot collection.
  Validates published source-window and continuation examples against current
  source-map, evidence and registered search schemas. Gestalt routing instructions
  distinguish routine byte budgets, authorized overflow and native edit authority.

- Defines complete executor review packets and independent root-observation
  comparison, including source/diff/report/raw-test digest checks, required-check
  inventories, first failures, risks and recomputed deltas. A bounded native
  helper retains complete result artifacts and expands changed/contradictory
  evidence only. Read denies remain enforced; unavailable evidence stays
  uncertain. Readiness never grants lifecycle acceptance or proves witness/CI
  freshness. Tests plant changed candidates, forged hashes and hidden failures.

- Reuses current-authorized, digest-verified evidence captures and bounded
  runtime parses while preserving original observations and isolating changed
  execution/redaction contexts. Cached or transferred CI success requires a
  remote refresh; local digest validity never establishes remote freshness or
  candidate approval. Explicit local recapture follows a caller-run check.
  Adds bounded selected-failure followups with verified source references and
  full-report locators, without reconstructing unrelated diagnostic sections.

- Persists source-map snapshots and range findings/questions/references in the
  existing workspace content database, with searchable navigation metadata.
  Adds bounded current-source/delta retrieval, stale/moved detection, explicit
  wider context, and content-bound pages that reauthorize live bytes. Source
  and index failures stay explicit; saved notes never replace current pre-edit
  inspection. Conservative ordered line anchors preserve every differing gap.

- Adds repository/path/content source revisions and versioned result keys for
  declared candidate SHA/branch/dirty scope, dependency/config and environment
  digests, exact command/cwd/exit, and CI run/attempt/job. Missing identities
  fail closed. Relevant-entry manifests include untracked files and deletions;
  their caller must enumerate and independently verify the complete scope.
  Every ingestion reauthorizes current source bytes before exposing identities.
  Keys establish identity only, never freshness, independent review or approval.

- Bounds complete execute/file/batch/search MCP envelopes to 2048 UTF-8 bytes
  after decorations; explicit budgets span 1024–65536 bytes. Keeps complete
  authorized evidence behind digest-verified workspace/session continuation
  pages, with explicit unavailable/partial state on storage or capture failure.
  Routine executable-source echoes become operation/language/source digests,
  truthful nullable execution states and audit references. Explicit audit views
  stay bounded; native permission review and retrieval authorization remain.
- Deduplicates overlapping query windows by source revision and range while
  retaining matched-query attribution, chunk-local lines and source locators.
  Independent failure IDs and raw diagnostics remain recoverable even when
  intent summaries, snippets or outer envelopes omit them. Regression coverage
  includes actual MCP transport, restart, denies, Unicode and storage failure.
  The frozen payload benchmark records routine bytes separately from complete
  overflow/audit retrieval costs without changing planted inputs or expectations.

- Adds provider-counter accounting with source-scoped capture identities,
  explicit per-counter coverage across gaps/resets, and unknown quota. Measures
  MCP result JSON fields once after registered handlers return, including
  structured content and explicit error flags. Persists only numeric metadata,
  unique capture IDs and digests; unmeasurable observations remain null through
  analytics. Host rendering/transport framing, nested calls and delivery lack
  authoritative runtime visibility and remain estimates or explicitly unknown.
  Integration tests exercise the production wrapper, registered handlers,
  persistence and analytics with independently authored UTF-8 envelopes.
- Replaces the legacy `ctx_stats` savings narrative with a 2048-byte metrics
  summary, explicit coverage and null quota/savings when no compatible comparison
  exists. Retains full metrics behind session-scoped, digest-verified overflow
  pages that honor native Read denies and reject changed or symlinked artifacts.
  Raw provider counters are captured locally through the existing Codex Stop
  hook without forwarding conversations, collapsing missing fields or adding
  reasoning to output. Legacy pricing records remain excluded from raw coverage.
  Advances the stats sidecar to schema 3: byte counts are known lower bounds;
  incomparable token/dollar savings stay null, and obsolete lifetime estimation
  scans are removed from the response hot path.

- Adds `ctx_test_evidence` for authenticated argv-only `gh` capture and
  authorized local test ingestion, deterministic format adapters, private
  digest-bound manifests, scoped indexing and 2048-byte reports/followups.
  Preserves native permission hooks and represents incomplete, unsupported,
  contradictory and run-scoped artifact evidence explicitly. The server's
  tool wrapper forwards cancellation context to registered handlers.
  Normalizes raw GitHub API timestamp envelopes without changing source line
  locators, and validates JUnit counters at every nested suite scope. Packaged
  transport tests and remote benchmark cases use timestamped API log fixtures.
- Reuses digest-verified terminal GitHub captures within runtime evidence scope,
  with explicit refresh and original observation timestamps. Coalesces identical
  concurrent captures with independently cancellable subscribers, fencing cache
  writes and joins when refresh invalidates earlier work. Stable source
  identities include selected run/attempt/SHA/job/artifact or canonical local
  path and content digest; index reuse stays within each receiving session.
  Authorized manifest transfer rechecks source access and reindexes locally.
- Adds a metrics-only synthetic evidence benchmark with correctness, payload,
  followup overhead, fetch/index reuse and rerun gates. Its baseline is an
  uncached raw workflow; it makes no billing or model-latency claims.
- Retains only Codex plugin manifests, configuration, hook entrypoints, and
  user-facing documentation. Other host packaging, configuration, hook
  wrappers, website content, and release automation are omitted.
- Replaces the self-healing first-run launcher with a small `start.mjs` that
  resolves one replaceable external runtime, performs a read-only artifact
  preflight, and starts its `server.bundle.mjs`.
- Adds `scripts/prepare-runtime.mjs` for explicit locked dependency install,
  type-checking, bundle creation, validation, and preparation-manifest creation.
- Adds a staged external-runtime installer at
  `${GESTALT_HOME:-$HOME/.gestalt}/runtime/context-mode`, with version, platform,
  architecture, and Node ABI checked through the preparation manifest. Verified
  replacements remove the previous runtime and legacy version-directory tree;
  failed builds preserve the prior installation. It canonicalizes CLI entrypoint paths so symlinked marketplace or
  temporary directories still run preparation. This avoids dependence on
  Codex's replaceable plugin cache.
- Routes Codex hooks through a cache-local launcher into the external runtime.
- Adds an idempotent Codex integration reconciler. Marketplace setup and a
  legacy plugin `SessionStart` hook repair native MCP registration, stable-hook
  enablement, user-level hook launchers, and incomplete older installations
  while preserving unrelated TOML and JSON entries.
- Disables the plugin manifest contribution after installing its package and
  registers a native workspace-inheriting MCP launcher instead. This works
  around current Codex builds omitting session/workspace variables from plugin
  MCP child environments without starting duplicate servers or hooks.
- Treats Codex stable hooks as enabled when no explicit feature override exists,
  and recognizes the context-mode plugin under any Codex marketplace name.
- Validates plugin-provided hooks at Codex's conventional `hooks/hooks.json`
  path and accepts version-matched external-runtime and marketplace roots.
- Rejects Bun commands that exist on disk or PATH but fail a version probe,
  preventing broken package-manager shims from being selected for execution.
- Recovers a missing `CODEX_HOME` from Codex's installed plugin-cache path so
  MCP diagnostics, storage, and hooks stay inside the selected profile.
  MCP and hook entrypoints never build or repair the package.
- Hardens the spawned MCP doctor probe against bridge-only lifecycle state and
  one transient clean exit. Recovered probes remain visible as warnings, while
  persistent failures include launcher, child PID, and shutdown diagnostics.
- Moves the eight rewritten routing and command skills into the Gestalt plugin,
  giving Codex one provider for skill listing and enable/disable controls.
- Removes upstream self-update as a supported Gestalt repair path. Local repair
  may only use the versioned package shipped by this repository; the Codex
  integration reconciler rejects non-versioned or package-version-mismatched
  cache roots so test fixtures cannot replace the live MCP launcher.
- Keeps the upstream TypeScript adapter registry for now because server and CLI
  compilation share it. It is implementation residue, not a supported-host
  promise; extracting a Codex-only core is a separate architectural change.

- Canonicalizes evidence-test temporary roots before constructing read policies,
  so symlinked macOS temporary directories retain the same authorization checks.

- Preserves supplied command exits and original observation timestamps across
  evidence transfers, records transfer time separately, and validates complete
  numeric TAP coverage before asserting certainty.
- Verifies paginated report bytes against a bounded cache of chunk digests,
  avoiding repeated full-report hashing while detecting changed reports.
- Resolves evidence candidates before containment and checks deny rules on both
  supplied and canonical paths; uses native separators for terminal-cache roots.

- Freezes an invented model-payload corpus with independent byte/counter
  expectations, source digests, the actual workspace baseline revision and
  dependency/environment identities. Replays production handlers in isolated
  baseline/candidate processes, counts overflow requests and envelopes, and
  keeps unsupported baseline measurements or serialization failures unknown.

- Keeps the tier-2 smoke assertion compatible with schema 3 null savings and
  restores legacy counters only for the authoritative Codex session, preserving
  unknown identity instead of borrowing the newest sibling session.

## Updating context-mode

The downstream acceptance runner repeats frozen production-handler comparisons,
gates the declared broad-plus-overlap retrieval denominator, preserves full
overflow/audit costs and rejects changed identities or lost findings. Scheduler
and configured-model-policy evidence is a separately pinned Mobile fixture gate;
payload savings never establish live model/quota or runtime-enforcement savings.
The repository-only model-trial harness reuses the Org comparison validator,
generates fixed fake-provider records with retry/reviewer costs and failure
evidence, and imports records read-only for coverage-aware distributions. It has
no live dispatch adapter; quota stays unobserved in synthetic runs.
The downstream CI overhead gate pins response/retrieval/bootstrap ceilings,
requires reviewed amendment metadata for increases against the supplied base,
and retains complete digest-bound diagnostics behind a bounded summary. Its
invented wake-trace contract supplements Mobile's owning production tests and
does not simulate runtime scheduling.
Its temporary artifact scope is canonicalized for macOS symlinked temporary
directories, with a CLI regression case. Live provenance tests await server
termination before removing their workspace to avoid teardown write races.
